# Question bank changelog

Every change to the bank, newest first. IDs are permanent: a question is corrected in place, never
renumbered, and a retired question keeps its ID with a note.

## 2026-09-23

- **Bank published.** Q1 to Q185 are the questions printed as Appendix C of the book's first interior,
  with the same numbers. Each now carries the chapters it draws on, a level and a type.
- **Q186 to Q227 added:** 42 coding exercises and challenges on the book's datasets, each with a
  runnable check. Python Q186 to Q195, pandas Q196 to Q207, SQL Q208 to Q219, challenges Q220 to Q227.
- **Reworded** to remove near-duplicates: Q80 (of Q25), Q104 (of Q47), Q106 (of Q46), Q151 (of Q139).
  Each pair is now linked as related.
- **Corrected** Q133: Chinchilla's data was nearly five times Gopher's, not four.
- **Beyond-the-book notes** added to Q13, Q82, Q83, Q120, Q133, Q155, Q156, Q158 and Q171, which use
  terms the book does not teach.
- Mock interviews M01 to M10 and checkpoints C01 to C03 added.
