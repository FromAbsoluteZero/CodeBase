## How to tell which applies

- If it runs, it is MIT. A file whose name is `starter.py`, `solution.py`, `solution.sql`, `check.py`
  or `_checklib.py` is code even though it sits inside the practice folder.
- If it explains, asks or answers, it is CC BY-NC-SA 4.0. Every generated practice page carries a
  one-line footer saying so.
- If you are meant to copy it into your own project and forget where it came from, it is CC0.
