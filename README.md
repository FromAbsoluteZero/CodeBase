# From Absolute Zero — Companion Code

Companion code, data and figures for **From Absolute Zero: Data science, machine learning, and AI —
from no code to transformers and production** by Shanmukh Behara (First Edition, 2026).

> **Repository status:** companion material for the book. ISBN 9798170522552. Publisher/imprint
> not yet confirmed. See `docs/BOOK_METADATA.md`.

---

## About the Book

Forty-five chapters running from a first line of Python to transformers, retrieval, agents and
production monitoring. The book assumes no programming, no calculus and no prior statistics.

Its central discipline: **every program in the book was executed and its real output printed on the
page.** This repository is how you run that code yourself instead of taking the book's word for it.

## Quick Start

```bash
git clone https://github.com/FromAbsoluteZero/CodeBase
cd CodeBase
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python scripts/verify_install.py
```

Then open any notebook, or run a chapter's code directly:

```bash
cd code/ch30
python c1.py
```

New to Git or Python? **Read `docs/HOW_TO_USE.md` first** — it starts from installing Python.

---

## Installation

Python **3.10 or newer**. Dependencies are pinned in `requirements.txt` to the versions the book's
printed output was produced under.

```bash
pip install -r requirements.txt
```

`requirements-optional.txt` holds packages needed by only two chapters (`shap` for Chapter 29,
`statsmodels` for Chapter 28). Install it only if you need those chapters.

---

## Running the Examples

Chapter code is split into numbered blocks matching the book's worked-example steps:
`c1.py`, `c2.py`, `c3.py` … Run them **in order** within a chapter — later blocks assume earlier
ones have defined their variables, exactly as the book presents them.

Files beginning with `_` (e.g. `_c3.py`) are self-contained versions of the same block, used to
regenerate the book's printed output. You do not normally need them.

## Data

**Every dataset here is synthetic and generated by code in this repository.** Nothing is downloaded,
no account is needed, no third-party or personal data is used or redistributed, and nothing can rot
behind a dead link.

Full provenance is in **`DATA_MANIFEST.csv`** and **`docs/DATA_GUIDE.md`**.

Regenerate everything from scratch:

```bash
python scripts/regenerate_data.py
```

## Reproducibility

Every experiment is explicitly seeded. See **`docs/REPRODUCIBILITY.md`**, which distinguishes:

- **Exact reproduction** — the printed number should match digit for digit
- **Approximate reproduction** — small differences are expected and acceptable
- **Conceptual reproduction** — the direction and conclusion hold, the number may not

That distinction matters and the guide is explicit about which chapters fall where.

---

## Expected Results

The book prints the output of every program. If a number you get differs from the page, check in
this order: (1) your package versions against `requirements.txt`, (2) `docs/TROUBLESHOOTING.md`,
(3) `ERRATA.md`. If it still differs, that is a defect and worth reporting.
