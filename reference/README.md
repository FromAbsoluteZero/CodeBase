# Reference

Material from the book's back matter that is meant to be searched, copied and kept current, rather than
read once. The book keeps the reasoning; this folder keeps the lists.

| Folder or file | What it holds | From |
|---|---|---|
| [cheatsheets/](cheatsheets/README.md) | pandas, SQL, Python, errors, charts, statistics and modelling, constants, checks, and a new scikit-learn sheet; every row names its chapter | Appendix D (*Quick Reference* in print keeps the constants, the checks and the three costliest mistakes) |
| [ai-assistant-prompts.md](ai-assistant-prompts.md) | the complete prompt library with the reasoning behind each prompt, one copy button per prompt | Appendix E (the principle, the routine, the checklist and six prompts stay in print) |
| [git/](git/README.md) | getting something back, working on the same file as someone else, the first push, conflicts, what to do about a committed secret | Appendix A (which stays in print in full) |
| [portfolio/](portfolio/README.md) | the three projects Chapter 45 asks for, what to avoid, and a bank of [project framings](portfolio/project-ideas.md) | Appendix B (which stays in print in full) |
| [templates/](templates/) | files to copy into your own projects: a [README template](templates/README_TEMPLATE.md), the [project checklist](templates/PROJECT_CHECKLIST.md) and [`analytics.gitignore`](templates/analytics.gitignore) | Appendices A and B |

The interview question bank, mock interviews and coding exercises are in [../practice/](../practice/README.md).
