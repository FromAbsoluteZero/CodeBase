# Cheat sheets

The operations you will look up most often, one sheet per topic, expanded from Appendix D of the book.
Each row names the chapter that teaches it. The printed appendix (now *Quick Reference*) keeps the three
things worth having on paper: the constants, the checks, and the three costliest mistakes.

| Sheet | For |
|---|---|
| [pandas.md](pandas.md) | loading, selecting, filtering, grouping, merging, reshaping, dates |
| [sql.md](sql.md) | the six clauses and their execution order, joins, NULL, windows, CTEs |
| [python.md](python.md) | the Python you will forget and look up |
| [errors.md](errors.md) | reading a traceback, and what each common error means |
| [charts.md](charts.md) | which chart for which question, and the rules that stop a chart lying |
| [statistics-and-modelling.md](statistics-and-modelling.md) | one-line definitions that interviewers and reviewers expect you to have straight |
| [constants.md](constants.md) | the numbers worth memorizing |
| [checks.md](checks.md) | the checks worth running every time |
| [scikit-learn.md](scikit-learn.md) | the pipeline, split, tune and evaluate patterns the book uses |

Print one sheet at a time from the browser, or open the raw file in any editor.
