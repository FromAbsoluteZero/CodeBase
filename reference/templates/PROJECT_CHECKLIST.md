# Project checklist

Print it, or copy it into your project's README and tick as you go. From Appendix B of *From Absolute
Zero*, with the credential rule from Appendix A. CC0 1.0: copy it freely.

- [ ] The question names a decision and someone who would make it
- [ ] The data required real cleaning, and the decisions are documented
- [ ] A baseline exists, and the result is compared against it
- [ ] Nothing was fitted before the train-test split (no leakage)
- [ ] The README states the finding in the first two sentences
- [ ] Every number in the README can be reproduced from the notebook or scripts
- [ ] Limitations and what you do not know are stated explicitly
- [ ] The write-up says "associated with", not "causes", unless the design supports the stronger word
- [ ] No data files and no credentials are committed; `.gitignore` was written before the first commit
- [ ] The repository runs from a clean clone with the steps in the README
- [ ] Somebody who is not you has read it and understood the conclusion
