# Code of Conduct

## In short

Be decent. This repository exists to help people learn.

## Expected

- Assume good faith, especially from beginners
- Give specific, actionable feedback
- Accept correction gracefully — the book has been corrected many times, and is better for it

## Not acceptable

- Personal attacks, harassment or discriminatory language
- Dismissiveness toward people learning the material
- Publishing others' private information

## Scope

Applies to issues, pull requests, discussions and any other space representing this project.

## Reporting

Report unacceptable behaviour to **b.shanmukh94@gmail.com**. Reports will be reviewed and handled
confidentially.
