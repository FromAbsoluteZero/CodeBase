# Security

## Scope

This is an educational companion repository. It contains no service, no server, no
authentication and no network calls. The realistic risks are about what users might add, not
about what ships here.

## What this repository deliberately does not contain

- No API keys, tokens or credentials
- No `.env` files
- No private or personal data — every dataset is synthetic and generated by scripts here
- No network calls, downloads or external API dependencies
- No model weights

Nothing in this repository requires an account, key or secret to run.

## If you fork or extend this repository

**Never commit credentials.** The `.gitignore` excludes the usual offenders (`.env`, `*.key`,
`*.pem`, `secrets/`, `credentials*`), but `.gitignore` only helps for files you have not already
committed.

If you add code that calls an external API:

1. Read the key from an environment variable — never a literal in source.
2. Keep the key in `.env`, which is git-ignored.
3. If a key is ever committed, **rotate it immediately**. Removing it in a later commit does not
   remove it from history.

## Reporting a problem

For a security issue in this repository, please open a GitHub issue **without including the
sensitive detail itself**, and a maintainer will follow up on a private channel.

Contact: **b.shanmukh94@gmail.com**

## Not a security guide

Chapter 44 covers privacy and re-identification, and Appendix A warns against committing data or
credentials. Neither makes this book a security reference. Consult appropriate guidance before
handling real personal data.
